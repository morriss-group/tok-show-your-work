# Show your work: one Facebook comment on a TOK question

**The question** (IB Theory of Knowledge, Knowledge Question of the Week):
*As knowers, do we have a moral responsibility to verify information before sharing it in digital spaces?*

**The one-line answer I gave:** Yes. The duty scales with how far the claim can travel and how much it can hurt someone if it is wrong.

This folder is the factory behind that comment. Not my whole AI history, not a manifesto. Just what produced this one answer, in the order it happened, so a student can see how much of the answer was mine, how much was a machine's, and what a free tool said when asked the same thing.

## The pipeline, in order

1. A classmate's teacher posted the question. (`workflow/01`)
2. I pasted it into Claude Code and asked for a research brief to give a second AI, Grok. That brief is a prompt, and it already chose the philosophers, the harm cases, and the demand for a fair "no." (`workflow/02`)
3. Grok Heavy answered the brief, not the class question. (`workflow/03`)
4. I gave Grok's research back to Claude Code and asked for a short comment in my voice. (`workflow/04`)
5. I edited it, posted it, edited it again, and deleted it. (`workflow/05`, `workflow/06`)
6. I asked Google AI Mode the class question the way a classmate would, once, as a control. (`workflow/00`, `COMPARE.md`)
7. I wrote the version with the disclosure. (`workflow/07`)

## The tools, plainly

Claude Fable 5.1 through Claude Code, and Grok Heavy, a research tier that costs about $300 a month. Most people in the thread don't have that stack. That's part of the point: the free answer to the same question also said "yes," but it stayed general. The paid pipeline bought particular cases, a philosopher, a proportional duty, two limits on it, and a warning about chatbots. It did not buy permission to say yes; the cheap tool said yes too.

## Two things this folder is meant to show

**The prompt and the tool change the answer.** Compare the teacher's question (`01`) with the brief Claude wrote for Grok (`02`). Grok never saw the class question alone. Then compare Google's one-shot answer (`00`) with the pipeline's (`07`). Same verdict, different depth. Iterating the brief until the paragraph sounded right would have been the shipowner's move; the brief was not the check.

**Two paid models are not two checks.** Claude wrote the brief, Grok answered it, Claude rewrote Grok. That's one distribution of internet text sampled twice with extra confidence. The comment says "asking two machines that read the same internet is not checking twice." That sentence applies to how the comment was made.

The first post said all of the above about chatbots and none of it about itself. Hiding the pipeline after writing that paragraph undercut the piece. So it came down, and this folder exists.
