# What is GitHub, and why is a Facebook comment sitting on it?

Three weeks before writing this, I didn't know either. Here's the version I needed.

## The short answer

GitHub is a website where people keep files in folders that remember every change ever made to them. That's it. The files are usually computer code, but they can be anything: essays, drafts, notes. You're looking at one of those folders right now. You don't need an account to read it. Tap a file name and it opens.

## What "remembers every change" means

Most folders on a computer only hold the current version of a file. A GitHub folder, called a **repository** or **repo**, holds the current version *and* every earlier version, with a note on who changed what and when. Those saved moments are called **commits**. Click "History" on any file here and you'll see the trail: the first draft, each edit, the deletion, the replacement. Nothing gets quietly rewritten. That's why it fits a folder whose whole point is showing work.

## Why developers use it

Software is written by many people editing the same files at once, often strangers on different continents. GitHub solved three problems for them:

1. **Nobody overwrites anybody.** Two people can change the same file and the site shows exactly where they disagree, line by line, before anything is merged.
2. **Every mistake can be undone.** Because every version is kept, a bad change is one click from being reversed.
3. **Anyone can propose a change without permission.** You copy the folder, make your edit, and send it back as a **pull request**: "here's what I'd change, and why." The owner reads it and accepts or declines. Strangers improve each other's work this way every day.

## What it did for open source

**Open source** means the code is public and anyone may use, read, and improve it. Before sites like this, sharing code meant mailing files around and hoping. GitHub made it one link. The result is that most of the software running the modern world, the web servers, the phone operating systems, the tools inside every app you use, is built in public, on this site or ones like it, by people who mostly never meet. The AI tools that drafted this comment were themselves built on thousands of open-source pieces hosted here.

## How to read this folder without knowing any of that

- The file list is the table of contents. `README.md` is the front page; `INDEX.md` explains every file in one line each.
- Files ending in `.md` are plain text with light formatting. They open in your browser.
- The `workflow` folder is the sequence, numbered 00 to 07. Read them in order and you'll watch the comment get made.
- "Commits" at the top shows the history. Click it if you want to see when each file appeared or changed.
- If something looks wrong to you, there's a way to say so on the site (an **issue**), or you can just reply on Facebook.

## Why put a school-discussion comment here at all

Because the comment argues that sharing something you haven't checked is a moral act, and the honest thing to do after writing that is to let people check the comment. A folder that keeps every version, that anyone can read, and that shows the machine's draft next to the human's edits, is the simplest way I know to do that. The tool was built for programmers. It turns out it's also a decent way to hand in your homework.
